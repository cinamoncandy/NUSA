# WO-AI-009 Outcome Attribution Evaluation Plan

Scope: PAPER/Research zero-authority learning evidence only.

This implementation evaluates whether NUSA can deterministically classify supported post-outcome failure hypotheses without turning model narrative, provider majority, hypothetical scenarios, or synthetic fixtures into causal proof.

## Before / after truth

The pre-WO-AI-009 system has verified prediction/outcome calibration, provider disagreement evidence, and governed scenario sensitivity, but no canonical per-forecast attribution record, immutable learning episode, holdout leakage gate, or advisory lesson memory.

The WO-AI-009 evaluator reports only attribution-engine quality:

- known-cause recovery rate on controlled cases;
- ambiguity abstention accuracy;
- false-attribution rate;
- unresolved rate;
- deterministic holdout/leakage rejection;
- replay-conflict rejection;
- synthetic/hypothetical realized-learning-credit rejection;
- immutable memory replay/supersession/expiry behavior.

Synthetic fixtures are not evidence of market causality, predictive alpha, or profitability. Real-world attribution-effectiveness claims require VERIFIED_RUNTIME resolved outcomes and held-out longitudinal observations.

## Net-benefit accounting

This first runtime slice is deterministic and introduces no new provider/model calls. Therefore model-token and provider-failure deltas are expected to remain zero for the attribution engine itself. Latency and storage overhead must remain bounded by exact-head CI/benchmark evidence before completion. If later attribution replay invokes a provider, it must consume the existing WO-AI-006 enclosing resource budget and cannot instantiate an independent unlimited budget.
