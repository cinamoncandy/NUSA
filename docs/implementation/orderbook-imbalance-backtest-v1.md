# Orderbook Imbalance Backtest v1

This research backtest executes each decision on the following orderbook snapshot. It models spread-side execution, fees, slippage, and a visible-depth participation cap. Results include immutable fills, closed trades, an equity curve, drawdown, risk-adjusted metrics, turnover, exposure, and a deterministic result hash. Open positions are marked to the final mid price. Invalid identifiers, chronology, references, hashes, transitions, and numeric values are rejected.
