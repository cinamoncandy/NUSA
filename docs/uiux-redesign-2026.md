# NUSA Mobile UI/UX Redesign 2026

Direction: institutional fintech + AI control room. Calm, premium, operational.

## Hierarchy
1. Equity / account truth
2. AI decision state
3. Market / trade / portfolio navigation
4. Safety and runtime diagnostics

## Rules
- One primary action per screen.
- PAPER/LIVE/capability state must come from runtime truth, never decorative labels.
- Dark-first graphite surfaces with restrained AI signal accents.
- 48px+ touch targets and readable supporting text.
- Cards are grouped by decision context, not backend module boundaries.
- Diagnostics stay secondary but one tap away.
- Real-capital actions are visually isolated from normal browsing.
- Visual changes must preserve existing test IDs and safety semantics.

This document grants no execution authority and changes no trading permissions.
