# NUSA Mobile UI/UX Redesign 2026

Direction: institutional fintech + AI control room. The mobile app must feel calm, premium, and operational rather than decorative.

Principles:
- primary information first: total equity, market, AI state, risk state
- one strong action per screen
- PAPER/LIVE/capability states are runtime-derived, never decorative labels
- dark-first graphite canvas with cobalt/aqua signal accents
- 48px+ touch targets, readable 12–16px supporting text, compact but not cramped
- bottom navigation behaves as a floating control dock
- diagnostics are secondary but always one tap away
- destructive or live-capital actions are visually isolated from normal navigation

This document is visual/interaction guidance only and grants no execution authority.
