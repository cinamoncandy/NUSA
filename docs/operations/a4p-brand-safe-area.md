# A4P Brand Asset Safe Area

The A4P mark is a compact protected-flame and eye symbol. Keep clear space equal to
one quarter of the symbol viewBox on every side. Do not crop the shield, add a drop
shadow, rotate the mark, or place status-warning cracks inside it.

Use `nusa-a4p-symbol.svg` for compact surfaces, `nusa-a4p-lockup.svg` for
horizontal headers, and `nusa-a4p-monochrome.svg` where color is unavailable.
The Windows icon is `build/nusa-a4p.ico`; the artwork is drawn on a full-bleed
square so Windows can apply its own mask.

Minimum display sizes: 20px compact symbol, 120px horizontal lockup. On dark
backgrounds use the supplied files unchanged. On light backgrounds use the
monochrome variant or preserve at least a 4.5:1 text contrast ratio.
