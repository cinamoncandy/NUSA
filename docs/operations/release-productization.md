# 도깨비 설치·사용 안내 (WO-0034-A4O)

이 문서는 **컴퓨터를 잘 모르셔도 따라 하실 수 있게** 썼습니다. 순서대로 읽으시면 됩니다.

이 앱은 **연습용(모의) 거래 도구**입니다. **실제로 돈이 오가지 않습니다.**

---

## 1. 첫 실행 안내

앱을 처음 켜면 안내 화면이 먼저 뜹니다. 아래 다섯 가지를 확인하고 **확인했습니다**를 누르시면
됩니다.

| 안내 | 뜻 |
| --- | --- |
| 실제 주문 기능이 꺼져 있습니다 | 진짜 매수·매도 주문을 넣는 기능 자체가 없습니다 |
| Private API를 사용하지 않습니다 | 내 계좌에 접근하는 통신을 하지 않습니다 |
| API 키가 필요 없습니다 | 키를 넣는 화면 자체가 없습니다 |
| 체결은 전부 가상입니다 | 기록만 남고 실제 자산은 그대로입니다 |
| 시세는 공개 데이터입니다 | 누구나 볼 수 있는 업비트 공개 시세만 씁니다 |

**이 안내는 한 번만 뜹니다.** 앱을 업데이트해도 다시 뜨지 않습니다.

다만 **안전 정책 자체가 바뀌면 다시 뜹니다.** 버전 숫자가 올라간 것만으로는 다시 뜨지 않습니다.
"실제 주문을 하지 않는다"에 동의하신 것이, 빌드 번호가 바뀌었다고 해서 다른 것에 동의하신 게
되지는 않기 때문입니다.

다시 보고 싶으시면 **설정 → 첫 실행 안내 다시 보기**를 누르시면 됩니다. 다시 본다고 해서 이미
확인하신 기록이 지워지지는 않습니다.

---

## 2. 앱 정보 (About)

**앱 정보** 칸에서 다음을 보실 수 있습니다.

- 앱 이름, 버전, 빌드 번호, 커밋
- Electron / Node 버전
- 운영체제와 아키텍처
- 현재 모드 (PAPER)
- **LIVE TRADING DISABLED** — 실제 거래 비활성 표시
- 업데이트 채널과 서명 정책
- 라이선스·저작권

그리고 버튼 세 개가 있습니다.

- **로그 폴더 열기**
- **Evidence 폴더 열기**
- **사용자 데이터 폴더 열기**

> 화면에는 **폴더 경로가 글자로 표시되지 않습니다.** 버튼으로만 열립니다.
> 앱 정보 화면을 캡처해서 공유하실 때 PC 사용자 이름이 같이 새어 나가지 않게 하기 위해서입니다.

---

## 3. 설정

| 항목 | 설명 |
| --- | --- |
| 테마 | 시스템 설정 따름 / 어두운 / 밝은 |
| 로그 상세도 | 오류만 / 경고 이상 / 일반(권장) / 상세 |
| 로그 보관 기간 | 1~90일 |
| 진단 정보 표시 | 진단 칸을 보일지 |
| 알림 표시 | 알림을 보일지 |

**설정에 없는 것:** API 키 입력칸, 실제 거래 켜기 스위치, Private API 켜기 옵션.
"꺼져 있는" 게 아니라 **아예 없습니다.**

배포된 앱에서는 로그 상세도를 **상세(DEBUG)** 로 두셔도 **일반(INFO)** 까지만 적용됩니다.
화면에 그렇게 안내가 뜹니다.

---

## 4. 로그 위치와 보관 정책

로그는 **사용자 데이터 폴더 안 `logs`** 에 쌓입니다.

- 일반 로그: `app-날짜.log`
- 크래시 로그: `crash-날짜.log` (따로 저장됩니다. 문제가 났을 때 제일 먼저 보는 파일입니다)

**로그가 무한정 쌓이지 않습니다.** 세 가지 한도가 동시에 걸려 있고, 그중 가장 엄격한 것이
적용됩니다.

| 한도 | 값 |
| --- | --- |
| 파일 하나 크기 | 2 MB |
| 파일 개수 | 10개 |
| 보관 기간 | 설정한 일수 (기본 14일) |
| 전체 용량 | 20 MB |

한도를 넘으면 **오래된 것부터** 지워집니다. 최신 로그가 마지막까지 남습니다.

로그에는 세션 번호(sessionId), 실행 번호(runId), 오류 코드가 함께 기록됩니다.
그리고 **비밀번호·키처럼 보이는 값은 기록되는 순간 가려집니다.** 나중에 지우는 게 아니라
처음부터 안 적습니다.

---

## 5. Evidence 위치

관측 기록(Evidence)은 **사용자 데이터 폴더 안 `shadow-evidence`** 에 세션별로 저장됩니다.

**이 폴더는 어떤 기능으로도 지워지지 않습니다.** 설정 초기화로도 지워지지 않습니다.
앱에 "Evidence 삭제" 버튼은 없습니다.

---

## 6. 진단 정보 내보내기

문제가 생기셨을 때 **앱 정보 → 진단 정보 내보내기**를 누르시면, 지원에 필요한 자료가 **ZIP 파일
하나**로 만들어집니다.

들어가는 것:

- 앱 버전, 운영체제
- 실행 번호(runId), 세션 번호(sessionId)
- 최근 로그, 크래시 기록
- 복구 상태, 시장 재연결 진단
- 안전 진단 요약
- Evidence **메타데이터** (목록·상태만)
- 최근 오류 코드

**들어가지 않는 것:**

- API 키·자격 증명 (애초에 저장하지 않습니다)
- 개인정보
- Evidence 원본 파일 (기록 자체는 PC에 그대로 둡니다)
- 사용자 폴더 전체 복사본

> 폴더를 통째로 담지 않고 **필요한 파일만 이름을 지정해서** 담습니다. 나중에 누가 그 폴더에
> 무언가를 더 넣더라도 자동으로 딸려 가지 않게 하기 위해서입니다.

ZIP 안의 `manifest.json` 에 **무엇이 들어갔고 무엇을 뺐는지** 적혀 있습니다.

---

## 7. 사용자 데이터 위치

사용자 데이터 폴더(윈도우 기준 `%APPDATA%\Dokkaebi`) 아래가 이렇게 나뉩니다.

```
settings/    설정, 첫 실행 확인
logs/        로그
shadow-evidence/   관측 기록 (Evidence)
recovery/    복구 기록
crash/       비정상 종료 표시
diagnostics/ 내보낸 진단 ZIP
```

개발용으로 실행하면 **`-dev` 가 붙은 별도 폴더**를 씁니다. 개발 중 만든 실험 기록이 사용자의
미완료 기록으로 잘못 보이지 않게 하기 위해서입니다.

---

## 8. 설정 초기화

**설정 → 설정 초기화**

| 지워지는 것 | 지워지지 않는 것 |
| --- | --- |
| 화면 설정 (테마, 로그 상세도 등) | **Evidence** |
| 첫 실행 확인 상태 | **복구 기록** |
| | **크래시 기록** |
| | **감사 로그** |
| | **완료된 세션 기록** |

전체 데이터를 지우는 기능은 **만들지 않았습니다.**

---

## 9. 앱 정상 종료 방법

**창을 닫거나 종료를 누르시면 됩니다. 작업 관리자로 강제 종료하지 마십시오.**

종료를 누르면 화면에 진행 상황이 순서대로 표시됩니다.

1. 신규 신호 처리 중단
2. 시장 구독 종료
3. 타이머 정리
4. **Evidence 저장 마무리**
5. 복구 기록 작성
6. 정상 종료 기록

**3~4초 걸릴 수 있습니다.** 멈춘 게 아니라 기록을 마무리하는 중입니다.

**강제 종료 버튼은 없습니다.** 그 버튼이 할 수 있는 일은 4번을 건너뛰는 것뿐이고, 그러면
기록이 깨집니다.

한 단계라도 실패하면 **정상 종료로 기록하지 않습니다.** 다음 실행에서 복구 절차가 돌아갑니다.
실패했는데 정상이라고 적으면, 진짜 강제 종료와 구분할 수 없게 되기 때문입니다.

---

## 10. 업데이트

이 버전은 **자동 업데이트를 사용하지 않습니다.** 새 버전은 직접 내려받아 설치하셔야 합니다.

- 현재 버전은 앱 정보에서 확인하실 수 있습니다.
- 채널 구조(stable / beta)는 준비돼 있습니다.
- **서명되지 않은 설치 파일은 설치하지 않습니다.**
- 업데이트가 실패해도 **지금 쓰시는 버전은 그대로 유지됩니다.**

---

## 11. 설치 후 확인 절차

설치하신 뒤 아래만 확인해 주시면 됩니다.

1. 앱을 켠다 → **첫 실행 안내가 뜬다** → 확인
2. **앱 정보**에 `LIVE TRADING DISABLED` 가 보인다
3. **앱 정보**에서 버전이 보인다
4. **로그 폴더 열기**가 동작한다
5. **진단 정보 내보내기**가 ZIP을 만든다
6. 앱을 닫는다 → **종료 진행 화면이 뜨고 "정상적으로 종료했습니다" 로 끝난다**
7. 다시 켠다 → **첫 실행 안내가 다시 뜨지 않는다**

---

## 12. 문제가 생겼을 때 알려주실 것

**증거 폴더를 지우지 마십시오.**

1. **앱 정보 → 진단 정보 내보내기** 를 누릅니다
2. 만들어진 ZIP 파일을 보내주십니다
3. 아래를 같이 적어주시면 좋습니다

```
- 무엇을 하다가 생겼는지:
- 화면에 나온 문구:
- 앱 버전 (앱 정보에 있음):
```

**폴더 경로와 개인정보는 적지 않으셔도 됩니다.** ZIP 안에 필요한 정보가 이미 들어 있고,
민감한 값은 빠져 있습니다.

---

## 13. 출시 전 체크리스트

배포 담당자용입니다.

- [ ] `pnpm run typecheck` 통과
- [ ] `pnpm run build` 통과
- [ ] `pnpm run lint` 통과
- [ ] `pnpm test` 통과
- [ ] `pnpm run package:validate` 통과
- [ ] `pnpm run package:win` 로 NSIS 설치 파일 생성
- [ ] 설치 후 첫 실행 안내가 **한 번만** 뜨는지
- [ ] 앱 정보에 **LIVE TRADING DISABLED** 가 보이는지
- [ ] 배포 빌드에서 **DevTools 가 열리지 않는지**
- [ ] 배포 빌드에 **개발용 버튼·mock 화면이 없는지**
- [ ] 배포 빌드에 **source map 이 포함되지 않는지**
- [ ] 진단 ZIP 에 민감정보가 없는지 (`manifest.json` 의 `withheldFields` 확인)
- [ ] 설정 초기화 후 **Evidence·복구 기록이 남아 있는지**
- [ ] 관측 중 종료 시 **정상 종료로 기록되는지**
- [ ] 로그가 한도를 넘기면 **오래된 것부터 지워지는지**

---

## 14. 절대 하지 않는 것

- ❌ 실제 주문
- ❌ Private API 사용
- ❌ API 키 저장
- ❌ 자동 업데이트
- ❌ Evidence 삭제
- ❌ 복구 기록 삭제
- ❌ 안전장치 완화
