# NUSA Investment Performance Engine Acceptance Gates

A research capability may advance only when the evidence layer can falsify it.

## Benchmark integrity

PASS requires deterministic dataset identity, walk-forward OOS evidence, explicit costs, benchmark comparison, drawdown, turnover, coverage diagnostics, and reproducible ranking inputs.

## Strategy laboratory

PASS requires every strategy family to run behind the same benchmark contract. No strategy-specific metric exemptions.

## Champion/challenger

PASS requires evidence across multiple independent slices and rejection of excessive drawdown, cost burden, parameter instability, train/OOS degradation, and concentrated performance.

## Portfolio research

PASS requires PAPER-only risk budgets, concentration controls, correlation awareness, drawdown de-risking, and reversible strategy quarantine.

## Autonomous research

PASS requires bounded hypothesis generation, deterministic evaluation, durable provenance, no execution authority, and human-auditable promotion reasons.

## Forward validation

PASS requires ongoing comparison between research expectations and actual PAPER observations with explicit drift detection.

## LIVE readiness

No automated acceptance criterion in this roadmap can satisfy WO-0051. LIVE and real-money transition remains HUMAN_ENVIRONMENT_ONLY.
