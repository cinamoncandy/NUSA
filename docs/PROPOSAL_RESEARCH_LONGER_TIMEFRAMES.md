# 제안서: 더 긴 시간 단위(1시간·4시간 봉) 전략 Research 비교

- 상태: PROPOSED (주인 승인 전에는 아무것도 바뀌지 않음)
- 작업지시서: `.aipos/work-orders/WO-RESEARCH-20261006-LONGER-TIMEFRAMES.yaml`
- 안전: PAPER_ONLY · liveAuthority=NONE · productionMutationAllowed=false · aiAuthority=ZERO_AUTHORITY
- 이 제안은 Research 비교만 다룹니다. 실행 중인 PAPER 전략, 자본, 위험 한도, 신뢰도 기준은 바꾸지 않습니다.

## 1. 왜 필요한가

현재 PAPER 기준 전략은 SMA 5/20 이고, 1분봉 기준으로 동작합니다 (#2546).
오늘 손실 매도 3건은 모두 이 전략이었고, 그래서 하루 연속손실 한도(3회)에 걸렸습니다.

Upbit 공개 1분봉 약 50시간(2026-10-04 ~ 10-06)으로 오프라인 재생해 보았습니다.
비용은 왕복 0.15%(수수료 0.05%×2 + 슬리피지 0.05%)로 잡았습니다.

| 전략 (1분봉) | BTC 앞/뒤 절반 | ETH 앞/뒤 절반 |
|---|---|---|
| SMA 5/20 (현재) | −7.7% / −7.7% | −9.2% / −8.5% |
| SMA 20/60 | −2.7% / −3.0% | −3.2% / −3.0% |
| Bollinger 20×2 | −5.1% / −5.5% | −5.9% / −5.5% |
| Donchian 60 | −1.1% / −3.1% | −1.4% / −2.2% |

결론: 1분봉에서는 모든 전략이 손실이었습니다.
비용 전 평균 수익은 거의 0이었고, 비용(0.15%)이 손실을 만들었습니다.
문제는 전략 종류보다 **시간 단위가 너무 짧다는 것**입니다.

## 2. 예비 관찰: 긴 시간 단위 (참고용, 승격 근거 아님)

| 전략 | BTC 60분 앞/뒤 | ETH 60분 앞/뒤 | BTC 240분 앞/뒤 | ETH 240분 앞/뒤 |
|---|---|---|---|---|
| 보유만 | +15.2% / +6.4% | +23.7% / +7.8% | −23.0% / +0.6% | −28.1% / +5.1% |
| SMA 5/20 | −4.8% / −0.5% | −2.8% / −7.4% | −8.2% / +8.0% | −2.9% / +13.4% |
| SMA 20/60 | +7.1% / +0.1% | +12.7% / −9.3% | −1.9% / +18.2% | +0.3% / +21.2% |
| Donchian 20 | +8.2% / +2.6% | +12.3% / −5.5% | −7.1% / −6.2% | −7.7% / +2.5% |

데이터 기간: 60분봉은 2026-07-15 ~ 10-06, 240분봉은 2025-11-07 ~ 2026-10-06 입니다.

정직한 해석:

- 긴 봉에서는 비용 손실이 크게 줄고, 일부는 플러스입니다.
- 하지만 기간에 따라 결과가 크게 바뀝니다. 예: ETH 60분 SMA 20/60 은 앞 절반 +12.7%, 뒤 절반 −9.3% 였습니다.
- 거래 수가 적어서(7~30건) 통계적으로 약합니다.
- 상승장에서는 그냥 보유한 것보다 못한 경우가 많습니다.
- 그래서 **이 표만으로는 어떤 전략도 승격할 수 없습니다.**
- 정식 Research 비교가 필요하다는 근거로만 씁니다.

## 3. 제안 내용

1. 기존 Research 실험 오케스트레이터에 비교 세트를 추가합니다. 새 커널이나 프레임워크는 만들지 않습니다.
   - 시간 단위: 1분, 15분, 60분, 240분
   - 전략군: SMA 크로스, Donchian, Bollinger (#1812 승인 시)
   - 비교 기준: 보유만 하는 경우
2. 평가 규칙은 AGENTS.md 의 트레이딩 연구 규칙을 그대로 따릅니다.
   - 수수료, 슬리피지, 지연, 결측 데이터를 반영합니다.
   - walk-forward 또는 OOS(표본 외) 검증을 필수로 합니다. 좋은 구간만 골라 쓰지 않습니다.
   - 장세별 성과, 최대 낙폭, 노출, 회전율, 파라미터 안정성을 기록합니다.
   - 보유만 하는 경우보다 위험 조정 성과가 낮으면 탈락입니다.
3. 결과는 기존 Governance Feedback → Candidate N+1 경로로만 넘깁니다.
   - 통과한 후보만 PAPER 비교 대상이 됩니다.
   - PAPER 증거 없이 LIVE 후보가 되는 일은 없습니다.
4. 긴 봉 전략이 PAPER 로 갈 경우, 하루에 거래가 거의 없을 수 있습니다.
   - 학습 주기(기간 마감 단위)도 그에 맞게 검토해야 합니다.
   - 이 부분은 별도 승인 항목입니다.

## 4. 바꾸지 않는 것

- 실행 중인 PAPER 전략(SMA 5/20, 1분봉)
- 신뢰도 기준 0.55, 연속손실 한도 3, 자본, 최소 주문
- LIVE 권한, AI 권한(ZERO_AUTHORITY), 실제 돈

## 6. 재현 방법

예비 수치는 Upbit 공개 캔들 API(`/v1/candles/minutes/{1,60,240}`)를 받아서 계산했습니다.

- 진입·청산은 신호가 나온 봉의 종가로 했습니다.
- 비용은 왕복 0.15% 입니다.
- 데이터를 앞 절반과 뒤 절반으로 나눠 따로 계산했습니다.
- 이 스크립트는 저장소 밖의 일회성 분석이었습니다. 정식 비교는 3번의 Research 경로로 다시 수행합니다.
