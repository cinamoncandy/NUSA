# AC-0018 External Claims Boundary

The source material that motivated #1921 is treated as inspiration for workflow structure only. NUSA does not accept the following as facts or qualification evidence without independent, reproducible evidence:

- claims that a named frontier model can autonomously produce institutional-grade trading systems;
- claims that a one-person autonomous hedge fund can operate at a stated minimal monthly model cost;
- claims that a weekend implementation is equivalent to institutional research/engineering quality;
- claims that named firms validated the exact workflow or performance unless independently sourced;
- claims that OU, Avellaneda-Stoikov, Hawkes, Heston, or any other published model is profitable merely because it is mathematically established;
- claims that more agents, more model calls, or self-modification imply investment improvement.

NUSA may independently test falsifiable hypotheses inspired by public literature. Canonical NUSA evidence begins only at its own governed data, experiment, evaluator, cost, risk, OOS, and PAPER-forward boundaries.
