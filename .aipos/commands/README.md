# CORE directives

This directory contains durable CORE-issued directives addressed to canonical roles.

A directive is not permission to bypass an existing work-order or safety gate. When a directive overlaps an existing canonical work order, the existing owner/branch/PR must be reused and the directive acts as priority/handoff guidance rather than a duplicate implementation lane.

Status must be evidence-backed. `COMPLETED` is not valid merely because code was written, CI passed, or a merge occurred when acceptance criteria require runtime, continuity, or independent validation evidence.
